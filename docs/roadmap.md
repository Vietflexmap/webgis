# Roadmap

## 0.1 foundation

MapLibre factory, source/layer helpers, registry, feature interaction, measurement, parcel tools, Google Maps parser, XYZ helpers, Python CRS/geometry/tile/provider core, tests and CI.

## Next

- PMTiles protocol helper
- WMS/WMTS adapters
- GeoJSON/KML/GPX import/export
- MapLibre Draw integration
- editable measurement vertices
- print/export
- layer catalog schema
- FastAPI adapter
- VN-2000 validation fixtures from authoritative control points
- administrative-boundary package
- optional routing plugin
- documentation site and GitHub Pages demo

Before 1.0 public APIs may change with release notes. From 1.0 onward use semantic versioning and deprecate before removal.
