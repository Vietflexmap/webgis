# Notice

The architecture in this repository was informed by behaviors observed in a supplied WebGIS application: MapLibre source/layer creation, measurement, parcel highlighting, coordinate parsing and CRS conversion.

The implementation here is a clean, modular reimplementation intended for long-term Vietflex use. It does not intentionally copy private backend code, credentials, proprietary datasets, private API responses, user records or application-specific endpoints from the supplied system.

Before importing original assets, styles, datasets or substantial source fragments from another project, verify reuse rights and preserve required attribution/licensing.

Third-party runtime dependencies such as MapLibre GL JS, Turf, pyproj and Shapely remain subject to their own licenses.
